# Кодекс поведения

Проект небольшой, поэтому правила короткие.

## Ожидаемое поведение

- Обсуждайте код и поведение программы, а не человека.
- Критика по делу: что не так, как воспроизвести, что ожидалось.
- Уважайте чужой опыт: у кого-то другой провайдер, другая игра, другая версия Windows.
- Не публикуйте чужие персональные данные, отчёты и логи без согласия.
- Не используйте issues и pull request для рекламы, политики и оскорблений.

## Недопустимое поведение

- Оскорбления, угрозы, травля, дискриминация по любому признаку.
- Публикация чужих данных, скриншотов и переписки без согласия.
- Спам и навязчивая реклама.
- Намеренная порча обсуждений.

## Жалобы

Если столкнулись с нарушением, отправьте приватный отчёт: https://github.com/Deusu20/ZapretAuto/security/advisories/new. Этот канал виден только сопровождающему. Публичные разборы в issue не нужны.

Меры: предупреждение, удаление сообщения, блокировка. Решение принимает сопровождающий.

## Область действия

Правила действуют в issues, pull request, discussions и в других местах, где представлен проект.
