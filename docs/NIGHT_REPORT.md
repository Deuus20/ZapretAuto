# Ночной отчёт (18→19 октября 2026)

Работа шла автономно. Ниже — что сделано, что выяснилось и что требует вашего решения.

## Итог на утро

- Установлен и запущен **ZapretAuto 1.0.19** (обновлялся сам через GitHub), стратегия **ALT8**,
  слежение за играми и автопочинка включены.
- Релизы теперь собираются на GitHub Actions по тегу (тесты → exe → установщик → самопроверка exe → SHA-256 → публикация).
- 37 офлайн-тестов (включая тест интерфейса), CI зелёный на каждый push.

## Главные находки

1. **Тестер проверял сайты «не тем браузером».** Python отправляет TLS-приветствие, отличное от Chrome,
   а DPI и стратегии реагируют именно на него. Discord (Electron) и браузеры — это Chrome. Пример: при одной
   и той же стратегии Discord открывался для Python-проверки и не открывался для Chrome-подобной.
   Теперь все проверки идут с TLS-отпечатком Chrome (curl_cffi). Рейтинг стратегий перевернулся:
   семейство SIMPLE FAKE раньше было внизу (≈4/18), теперь лучшее (34/36 в финале).
2. **Wardogs провайдер не блокирует.** Матрица запусков (с нажатием клавиш на заставке, по 3 попытки):
   без обхода 2/3 и 0/3, с SIMPLE FAKE ALT 2/3 и 2/3, остальные 1–2/3. Вход в игру сбоит сам примерно в
   каждой третьей попытке; обход, похоже, немного помогает (4/6 против 2/6), но решающего значения не имеет.
   Раньше «Вход в систему…» часто означал просто ожидание нажатия клавиши.
3. **Ошибка лаунчера WD-L004** была из-за стратегии ALT3, ломавшей Fastly/Cloudflare — исправлено ещё
   вечером (проверки «не сломать лишнее»), а ночью слежение за играми перестало добавлять веб-адреса
   (80/443) игр в обход. Серверы матчей (UDP/TCP 1024–65535) обходятся как раньше.

## Что сделано за ночь

- Проверки с TLS-отпечатком Chrome; curl_cffi в сборке; режим `ZapretAuto.exe --selftest`.
- «Подобрать стратегию для этой игры»: сначала замер без обхода, каждый вариант 3 запуска,
  клавиши на заставке нажимаются сами, серверы считаются через WinDivert (видны UDP/Steam-сеть) и
  засчитываются только ответившие. Проверено на Wardogs (подобрал SIMPLE FAKE ALT) и Deadlock (34 сервера).
- Слежение за играми: без адресов 80/443 и лаунчеров, без перезапуска обхода первые 2 минуты игры,
  одноразовый сброс старых адресов.
- Общая база провайдеров: голосуют только отчёты 1.0.8+; база используется только при первой настройке
  и при ≥92%. Для МГТС в базе теперь SIMPLE FAKE ALT.
- После первой настройки — вопрос про автозапуск; уведомление о новой игре один раз.
- CI: тесты на каждый push; релиз по тегу собирается и публикуется на GitHub.
- Замер ресурсов: 77 МБ памяти без роста, ~0,04% CPU в простое.

- **1.0.10:** подбор в ~2,5 раза быстрее (149 с вместо ~400 с) — все проверки стратегии параллельно;
  оценка оставшегося времени; если обход не стартует/падает — программа сама пишет причину (например,
  файлы удалил антивирус); «Проверить доступ» в меню трея.
- **Ночное наблюдение:** ночью DPI почти не работает (без обхода открывалось 16 из 18 целей против 9 из 18
  вечером) — подбор в это время бессмыслен. Теперь подбор в такой ситуации сохраняет текущую стратегию.
- **1.0.11 — профили игр:** стратегия, найденная «Подобрать для игры», включается сама, пока игра запущена,
  и выключается после выхода (проверено вживую на подставной игре).

- **1.0.12–1.0.14:** фоновые проверки без скачивания 1 МБ (≈140 МБ/сутки экономии); проверка сервиса по
  большинству проб (меньше ложных тревог); подбор не меняет рабочую стратегию из-за шума; кнопка «Отменить»;
  **исправлен баг**: после неудачного подбора обход оставался выключенным; история смен стратегии в статистике.
- **Проверено вживую:** обновление zapret в установленной программе (1.10.2 → 1.10.3 + подбор), первый запуск
  на пустых данных (154 с до работающего обхода, вопрос про автозапуск, предложение поделиться),
  обучение `--hostlist-auto` (medium.com сам попал в список и открылся), «Сайт не открывается…» —
  LinkedIn и Rutracker у вашего провайдера режутся DPI и открываются через обход.

- **1.0.15–1.0.16:** диагностика ловит подмену DNS провайдером; подбор проверяет QUIC (HTTP/3) — выяснилось,
  что QUIC к Discord у МГТС блокируется и проходит лишь с частью стратегий (ALT3/7/8/9, SIMPLE FAKE ALT, default),
  поэтому лучшей стала **ALT8** (36 из 40); пауза обхода на 15 минут из трея; исправлено падение при выходе во
  время фоновой задачи (нашлось благодаря тесту интерфейса в CI).

- **1.0.17 — без обрывов в играх:** выяснилось, что winws сам перечитывает изменённые файлы ipset, поэтому
  новые серверы игры теперь добавляются без перезапуска обхода (раньше — перезапуск до раза в минуту, микрообрывы
  в матче) и почти сразу (~5 с).

- **1.0.18 — утечка ресурсов найдена ночным замером:** за 2,7 часа работы программа выросла с 680 до 772
  системных дескрипторов и с 7 до 11 потоков. Причина — потоковый режим библиотеки запросов (curl_cffi)
  в фоновых проверках. Исправлено; 300 запросов подряд — рост прекратился. Заодно: меньше перезапусков
  обхода (списки winws перечитывает сам), адреса VPN-серверов обновляются раз в минуту, нельзя сохранить
  пустой список. Для повторной проверки — `tools/leakcheck.py`.

- **1.0.19 — вторая утечка:** замер 1.0.18 показал, что дескрипторы всё ещё растут (~11 за 10 минут). Нашёл
  ускоренным воспроизведением: ежеминутная фоновая задача (обновление адресов VPN) оставляла по 1–2 дескриптора —
  внешние команды из потоков Qt и цикл ссылок у завершённых задач. Фоновые задачи переведены на потоки Python
  и освобождаются сразу; добавлен регрессионный тест.

## Требует вашего внимания

- **Подпись установщика** (меньше предупреждений SmartScreen/антивирусов): бесплатный вариант —
  заявка в SignPath Foundation для open source; подать может только владелец аккаунта GitHub.
- **Windows Sandbox** для проверки установщика «с нуля» — нужна виртуализация в BIOS.
- В Wardogs стоит поиграть пару матчей и посмотреть вкладку «Статистика» — качество связи в самом матче
  ночью проверить нельзя.
