# Приватность: что и куда отправляет программа

ZapretAuto не собирает телеметрию и не имеет своего сервера. Все сетевые обращения программы:

| Куда | Зачем | Что передаётся |
|---|---|---|
| `api.github.com`, `github.com`, `*.githubusercontent.com` | Проверка и загрузка обновлений ZapretAuto и zapret, списков IP, общей базы стратегий | Обычный HTTPS-запрос (GitHub видит ваш IP, как при открытии любой страницы) |
| `ipinfo.io` | Узнать номер сети провайдера (AS) для общей базы — только при подборе стратегии и при отправке отчёта | Обычный HTTPS-запрос; сервис видит ваш IP |
| Discord, YouTube, Google, Cloudflare, STUN-серверы Google/Cloudflare, `web.telegram.org` (если включён Telegram) | Проверки доступа | Обычные запросы, как из браузера |
| Серверы ваших игр (TCP) | Проверка, не стало ли соединение хуже после включения обхода | Попытка TCP-соединения |

## Отчёт в общую базу

Отправляется **только если вы нажали «Поделиться»** и подтвердили создание issue на GitHub
(от вашего аккаунта, публично). Содержимое отчёта:

```json
{
 "asn": "AS25513",
 "isp": "PJSC Moscow city telephone network",
 "zapret": "1.10.3",
 "app": "1.1.0",
 "choice": {"base": "ALT12", "picks": {"tcp:443:list-google": "FAKE TLS AUTO ALT"}},
 "score": 23,
 "total": 28
}
```

Ваш IP-адрес, имя компьютера и список игр в отчёт **не** попадают.

## Адреса серверов игр

Отправляются **только если вы нажали «Поделиться адресами…»** в разделе «Игры» и подтвердили создание
issue на GitHub (от вашего аккаунта, публично). Содержимое: версия программы, имена exe найденных игр,
адреса их серверов и подсети серверов входа (`/24`). Ваш IP-адрес в отчёт не попадает. В общей базе
([`games-db.json`](../games-db.json)) авторы хранятся только как короткий хеш имени на GitHub.

## Отчёт разработчику («Отправить отчёт…»)

Отправляется **только если вы нажали кнопку** и подтвердили создание issue на GitHub (от вашего аккаунта,
публично). Содержимое: ваше описание проблемы, версии ZapretAuto, zapret и Windows, стратегия, есть ли VPN,
найденные диагностикой проблемы и последние строки журнала. Имя пользователя Windows и все IP-адреса,
кроме адресов вашей локальной сети, заменяются на `<user>` и `<ip>`. Текст виден на странице до отправки.

## Режим zapret2

При первом включении программа скачивает файлы winws2 с `raw.githubusercontent.com`
(репозиторий [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)) — обычный HTTPS-запрос.

## Отчёт об ошибке

Файл zip сохраняется **только у вас** — вы сами решаете, кому его отправить. В нём: журнал программы,
результаты диагностики, настройки и результаты тестов. Имя пользователя Windows в путях заменено на
`<user>`. Список найденных игр и их IP-адреса там есть (в настройках) — если не хотите их показывать,
удалите `settings.json` из архива.

## Что хранится на компьютере

Папка `data\` рядом с программой: настройки, журналы (до 4 МБ), статистика за 30 дней,
списки сайтов и IP.
